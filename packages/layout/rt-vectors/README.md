# rt vectors

The TypeScript rt reference (packages/layout/src/rt-*.ts) on the rt oracle inputs, written by `pnpm run rt:oracle`.
ANIM-a2 requires the translated Swift and Kotlin to reproduce every record bit for bit and string for string. Do not edit.

`hold.json` records animations paused at `timeMs` at timeline time 0 and read `elapsedSeconds` of timeline time later.
