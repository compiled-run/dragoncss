## S3b objective (binding)
S3b, the text engine plus the S3a must-fix items. (1) Multi-line Ahem inline formatting (css-text-3 §4-§5, CSS2 §10.8). Break at spaces and U+200B only. Unbreakable words overflow. Trailing spaces hang. Line k's top is at k times the line height, with half-leading floored as in the existing deviation. Supported: line-height normal, number and px, including a line height below the glyph height; text-align start, end, left, right and center in ltr. justify stays unsupported unless a fixture with 2 or more lines proves it. (2) In webref 8.7.5 white-space is a shorthand: add its longhands white-space-collapse and text-wrap-mode to LONGHANDS, and accept white-space as a shorthand over them. Support collapse plus wrap (white-space: normal); nowrap is optional and needs a fixture. Any value that sets white-space-trim or another collapse mode is DRAGON_UNSUPPORTED_VALUE. The compiler does phase I whitespace collapsing and writes the collapsed text onto each text leaf. The engine validator rejects uncollapsed text under collapse. (3) Principle 3: resolved text nodes carry every inherited text property (font-family, font-size, line-height, color, text-align, white-space-collapse, text-wrap-mode), each with an Origin chain of kind 'inherited'. The lowering reads only the text node, never its parent. The chrome-dual lane compares each text node's colour channels with its parent's Chrome computed colour. (4) Loose text is wrapped by the compiler, not the engine. The lowering emits explicit anonymous boxes, with id <parent>:anon<k> and a fully specified style, for text mixed with block children (CSS2 §9.2.1.1) and for text directly in a flex container (css-flexbox-1 §4). The validator rejects a box that mixes text and box children, and the engine never creates boxes. Text runs from several text nodes (projection, branch or call boundaries) share one inline formatting context. (5) Text min-content and max-content inside flex (§9.9, automatic minimum size §4.5): a text item shrinks to its min-content and wraps, and a column item's height comes from its wrapped lines. (6) Parity: the capture adds per-line text fragments <text id>:line<j> from Range.getClientRects, and the engine emits matching line fragments. Every Chrome node is compared. A node only Dragon has is allowed only if its kind is 'anonymous', it is listed in the report, and all its text lines are compared; any other Dragon-only node fails. (7) Projected literal text conformance (api.md §10): an internal textTopology(compiled, assignment) returns, for each text address, the authored component, template id and Origin, the owner instance, the insertion parent and the origins of its inherited styles. Tree fixtures declare the expected topology by hand in fixture.json, and a test compares it for every case. (8) Remove the single-line-text context. Text rows are keyed by contexts the compiler computes from tree facts (for example text-in-block, text-in-anonymous-block, text-in-flex-item, text-as-anonymous-flex-item). A test requires every text row context to be proven by at least one passing case where the text wraps to 2 or more lines in that context. Remove any UnsupportedCode that becomes dead; the every-code-raised test stays. (9) Fixtures: at least 67 in total and at least 57 layout fixtures, from at least 10 new ones: text-wrap-spaces, text-wrap-zwsp, text-align-multi-line, text-line-height-multi-line (including negative leading), text-unbreakable-overflow, text-whitespace-collapse, text-anonymous-block-mixed, flex-text-anonymous-item, flex-text-min-content-shrink, flex-column-text-wrap, tree-projected-text (text projected into a slot whose insertion parent changes font-size or line-height by state, with every case run), plus at least one reject fixture (white-space: pre or a span tag). (10) S3a must-fix items. MF1: each tree fixture declares by hand in fixture.json its expected free states, its case count and its initial assignment; the test checks all three against the renderer and against Dragon's compiledCases, including which case is initial. MF2: include the profiles mode in the compile digest. Add a test that the default-condition entry exports none of createProjectWith, InternalOptions, NO_FAULTS or applyFix, and that createProject takes no options. MF3: applyFix refuses as stale two edits that start at the same offset in the same source when either is an insertion; add a test with both orders. MF4: whitespace-only text never produces an empty address; it is either removed by the collapse rule, with a test, or gets a unique address. MF5: every ChromeDeviation node names its branch, and the test requires at least one node per declared branch. MF6: new planted faults. dropInheritedText (a text node's font-size reverts to its initial value) must fail the layout lane on a multi-line fixture. breakOffByOne (a break one glyph late) must fail the layout lane on text-wrap-spaces. Both must pass with the fault off.
