# T103 G-IMP4: dead-rule dropping in the WPT importer

Worktree /tmp/dragon-imp4, branch imp4-dead-rules, commit 566f6e1e (local, not pushed). Based on origin/master 43da1152.

## What changed (packages/wpt only)
- **src/translate.ts:** `deadRule()` drops a top-level style rule only when all of these hold:
  - its selector list parses;
  - no selector has a pseudo-class or pseudo-element;
  - css-lite `matches` is a definite `false` for every selector on every element of the source tree. The tree includes removed harness nodes. In snapshot mode it is that state's DOM.

  Matching is case-folded (tags, ids, classes, attribute names and values), so quirks mode and case-insensitive attribute values can only keep a rule.

  Rules inside at-rules are never items, so they are kept. A dropped rule is cut whole, from its prelude through `}`, and no selector list is rewritten. Dead rules are left out of the id rewrite and the cascade guard. `Sidecar.deadRules` lists the dropped selector lists and is absent when there are none.

  The reftest mode drops nothing, because it has no Chrome confirmation path. The plants are `DeadRuleFaults` (`dropLiveRule`, `dropUnknownSelector`, `dropFirstStateOnly`), plus the `deadRuleDocument` hook the last one uses.
- **src/chrome.ts:** `runInChrome` counts `querySelectorAll` for each dropped list and reports `deadRulesLive`. A nonzero count or a list Chrome rejects counts as live.
- **src/snapshot.ts:** `liveDeadRulesInSnapshot` reruns the original page with a `checkLayout` hook and counts each state's lists at that state's call. A state the page never reached counts as live. `translateSnapshot` takes the faults.
- **src/run.ts:** a live dropped rule turns the record into `not-runnable` with `translate:dead-rule-live`, for static tests (Chrome pass) and for snapshot tests (at capture). `runSnapshotTest` takes the faults.
- **Tests:** test/dead-rules.test.ts (new; offline tests and Chrome 145 tests), test/data/dead-rules/{static,dynamic}.html, and 4 tests appended to test/translate.test.ts.
- **Regenerated:** expectations/web.json. snapshots/**, reftest-captures/** and web.reftest-layout.json were recaptured and are byte-identical. README numbers were updated and a "Dead rules" section added.

- `pnpm install`, `pnpm typecheck` and `pnpm test` pass: 85 files, 1847 tests.
- `pnpm wpt:run --target web --chrome-all --reftest-layout`:
  - **0 `dead rule live`.**
  - 80,855 rules are dropped in 237 files (186 static, 51 snapshot). Every one was confirmed by Chrome; no file was left unconfirmed.
- `pnpm wpt:update-expectations --target web`, then `pnpm wpt:check --target web --reftest-layout`: every entry matches. reftest-layout shows 0 differences, and the 20 verdicts are unchanged.
- **Plants (test/dead-rules.test.ts), each caught:**
  - `dropLiveRule`: Chrome reports `.box` as live, and Dragon fails.
  - `dropUnknownSelector`: Chrome reports `.c > .box:first-child` as live, and Dragon fails.
  - `dropFirstStateOnly`: Chrome reports `state 1: .wide .box` as live, and Dragon fails state 1.

## Deviations
- Dead-rule dropping is limited to check-layout mode, so reftest translations are unchanged. This keeps every drop Chrome-confirmed and the 20 reftest-layout verdicts fixed.
- Matching is case-folded, which is stricter than the spec's "css-lite false". This avoids quirks-mode and attribute-value false negatives.
- The README headline was already stale ("4 pass ... runnable 5") and was corrected to the check's 5/6.
