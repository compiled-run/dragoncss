## userAgentUnmodelled and userAgentForced

- **userAgentUnmodelled.** This covers every element-table tag and every key, per direction. It lists the properties in Chrome's full `getComputedStyle` list whose value differs from a `dragon-unstyled` sibling under the same parent. That sibling is given the element's declared and text-font values.
  - The list excludes LONGHANDS, their logical aliases and custom properties. An alias is a name that maps to a longhand once block and inline are replaced by top, bottom, left and right, and block-size or inline-size by height or width.
  - **Deviation:** the spec compares against a bare `dragon-unstyled`. That picks up values that only follow a modelled longhand. For example, `hr` has `text-decoration: rgb(128,128,128)` from `currentcolor`. Written into the style as an explicit colour, it makes the replica serialize `text-decoration` differently, so self-consistency fails.
- **userAgentForced.** This is a new export. It lists LONGHANDS whose Chrome value differs even after the declared values are applied, because neither `unset` nor `initial` can change them:
  - `input` `overflow-x`/`overflow-y: clip`. Probe: author `overflow-x: visible !important` still computes `clip`, so this is a UA `!important` rule;
  - `button`, `input` and `input[type=range]`: `display: inline-block`. Chrome adjusts the style of form controls, so display inline becomes inline-block.

  The declared tables omit these values by construction, because the declared capture diffs against `unset`.
- **New-key unmodelled values:**
  - button: `appearance: auto` and `cursor: default`;
  - input: `appearance: auto` and `cursor: text`;
  - range: `appearance: auto` and `cursor: default`;
  - a[href]: `cursor: pointer`, `text-decoration-line: underline` (plus the `text-decoration` and `-webkit-text-decorations-in-effect` mirrors);
  - img: `overflow-clip-margin: content-box`;
  - a and span: none.
- **text-align is not unmodelled.** The spec gives text-align as an example of an unmodelled property, but it is a LONGHAND at BASE. So button `text-align: center` is in `elementKeyDeclared`.
