The plain summary

  • Dragon compiles regular CSS at build time into native view properties.
  • Every result is proven against Chrome number by number, never by screenshots.
  • It has its own TypeScript layout engine: block, flex, text, positioning and right-to-left.
  • Milestone 1: 137 test fixtures and 258 cases pass. 8,671 of 8,671 boxes match Chrome exactly, to 1/64 px. 339,080 computed values are identical between the author's CSS and Dragon's output.
  • Support is labelled exact, caveat or unsupported. Nothing is marked supported without a passing test.
  • Now in progress (milestone 2): iOS and Android at parity. Native engines are generated from the one TypeScript engine, and each device lane is checked against Chrome.

  • iOS and Androidin progress, milestone 2
