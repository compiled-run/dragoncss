Dragon CSS, plainly

Write regular CSS once. Dragon compiles it at build time into native view properties, and proves the result against Chrome, number by number, never by screenshots.

Where each platform stands

  • Web: proven (milestone 1). Dragon's own TypeScript layout engine (block, flex, text, positioning, right-to-left). 137 test fixtures and 258 cases pass; 8,671 of 8,671 boxes match Chrome exactly, to 1/64 px; 339,080 computed values are identical between the author's CSS and Dragon's output.
  • iOS and Android: in progress (milestone 2), at parity. Native engines are generated from the one TypeScript engine, and each device lane is checked against Chrome.
  • macOS and Email: later. Nothing is claimed yet.

Support labels: exact, caveat, unsupported. Nothing is marked supported without a passing test.
