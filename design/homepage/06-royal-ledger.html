The plain summary

  • Dragon compiles regular CSS at build time into native view properties, proven against Chrome number by number, never by screenshots.
  • Its own TypeScript layout engine covers block, flex, text, positioning and right-to-left.
  • Milestone 1: 137 test fixtures and 258 cases pass. 8,671 of 8,671 boxes match Chrome exactly, to 1/64 px. 339,080 computed values are identical between the author's CSS and Dragon's output.
  • Web: layout, flex, text, colours and positioning are exact. iOS: layout is exact on the Linux-lane engine proof; paint (colours, borders, overflow) is caveat. Android is in progress in milestone 2.
  • Grid, z-index, position: fixed and position: sticky are unsupported everywhere and refused at build time.
  • Now in progress (milestone 2): iOS and Android at parity. Native engines are generated from the one TypeScript engine, and each device lane is checked against Chrome.
