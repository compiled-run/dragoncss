Dragon CSS, plainly

  • Regular CSS, compiled at build time into native view properties.
  • Its own TypeScript layout engine: block, flex, text, positioning, right-to-left.
  • Web: proven today against Chrome by numbers, not screenshots. 137 fixtures, 258 cases, 8,671 of 8,671 boxes exact to 1/64 px, 339,080 computed values identical.
  • iOS and Android: in progress (milestone 2). Native engines are generated from the one TypeScript engine; each device lane is checked against Chrome.
  • Support labels: exact, caveat, unsupported. Nothing is marked supported without a passing test.
  • Install: npm install dragon (coming soon; not yet published).
